# Northern Trains Data Engineering Tech Test

## What is this?

The Data Engineering Tech Test is designed as a simple challenge for Data Engineering role candidates at Northern Trains. The Tech Test is designed to be an interactive pair programming exercise, which will be conducted by one or two of our Data Engineering team.

## Why?

The Tech Test allows us to assess your technical and team working abilities and the level that you're working at.

### What the exercise is

This is a pair programming exercise and we would encourage you to ask questions and talk us through your thought process, just as we would in a real scenario.

### What the exercise isn't

This isn't a test of syntax or library knowledge. We just want to observe how you go about tackling a problem and how you work as part of an engineering team.

## How long will it take?

We expect the exercise to take about 1 hour.

## What to expect

The exercise is written in Python and we will make use of the `Pandas` and `PyTest` libraries. We have a 5 scenarios based on some mock data that we would like you to complete. These scenarios will cover:

- Data Ingestion
- Data Cleansing
- Data Aggregation

We've written some unit tests for each of the 5 scenarios, all we need you to do is fill out the blanks in the application code to make the unit tests pass.

This isn't a test of speed, and we may not get through all of the scenarios, don't worry if this happens.

We expect you to work with us, ask questions and talk us through your thought process.

## What are the rules?

There's a few ground rules:

- Share your screen with us.
    - This is so we can see your code editor so that we can gain insight into your process and offer assistance.
- No AI Tools.
    - Nowadays, we understand that Generative AI is an important tool in any Engineering workflow, howrever, the purpose of this exercise is to assess YOUR knowledge, not the knowledge of the LLM.

There's some things that are allowed and encouraged:

- Google (and other search engines) can be used to help, however, we would ask that you show us what exactly you're 'Googling' for.
- Ask us. We're here to help, this is a pair programming exercise, not an exam. Let's work through it together.

## What do I need?

To complete the technical test you will need the following:

- A computer or laptop with the following software or equivalent:
    - Microsoft Teams (can be accessed via the Web Interface).
    - A text editor you're comfortable with (we reccommend VS Code).
    - An environment with a Python interpreter installed.
        - This is so you can run the code you write.
    - Git Version Control
        - This is so you can clone down the technical test files.
- A GitHub account.
    - So that you can connect to GitHub and clone down the repository.
- Your smiley face and a can do attitude!

## Reasonable Adjustments

At Northern, we understand that everyone's different and that's something we embrace as an inclusive employer. If you feel that you need any reasonable adjustments to be made, please let our recruitment team know and we will endaevour to accomodate as best we can.
